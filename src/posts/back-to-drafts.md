September 15, 2026

Lately, I've been fucking around with different ways to organize my writing. I've bounced between editors, moved folders around, written scripts and automations, and tried to come up with the perfect file-based setup. Every time I thought I had it figured out, I found myself changing something again. Today I finally settled on where I want to do my writing and keep my notes.

I decided to move everything back into [Drafts](https://getdrafts.com). I’ve been using Drafts for more than ten years, know it inside and out, and already have actions that can do just about anything I can think of. Instead of using Drafts simply as a place to write before moving things elsewhere, I’m going to use it as the repository as well.

Drafts is where I write and store blog posts, notes, journal entries, and daily notes. When something needs to become a file or go somewhere else, a Drafts action can take care of it.
